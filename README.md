# Лендинг для SMM-услуг

Простой статичный лендинг для продвижения услуг по SMM. Сделан на чистом HTML/CSS/JS.

## Файлы проекта

- `index.html` - главная страница
- `style.css` - стили
- `app.js` - небольшой JS для интерактивности

## Как запустить

Откройте `index.html` в любом браузере двойным кликом.

## Что можно заменить

- Имя/никнеймы в блоке "Связаться" - ссылки на Telegram и VK
- Цены в блоке "Услуги" (вместо `от X ₽/...`)
- Тексты и названия кейсов
- Фотографии/обложки в кейсах (замените заглушки на реальные скриншоты)

## Рекомендации по хостингу

Бесплатно: [GitHub Pages](https://pages.github.com), [Netlify Drop](https://app.netlify.com/drop), [Cloudflare Pages](https://pages.cloudflare.com)

Достаточно просто загрузить все 3 файла в папку и опубликовать.
